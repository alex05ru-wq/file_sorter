# Сортировщик файлов

Скрипт на Python, который наводит порядок в папке (например, «Загрузки»): раскладывает файлы по подпапкам в зависимости от типа.

## Что умеет

- Раскладывает файлы по папкам: Документы, Изображения, Видео, Музыка, Архивы, Программы, Образы, Торренты, Прочее
- **Режим проверки** по умолчанию: сначала показывает, что будет сделано, и ничего не трогает
- Не затирает файлы: если имя уже занято, добавляет `(1)`, `(2)`…
- Не трогает папки, скрытые и недокачанные файлы
- Сохраняет отчёт о сортировке в `отчёт_сортировки.txt`
- Категории и расширения легко дополнить в начале скрипта

## Технологии

- Python 3, только стандартная библиотека (ничего устанавливать не нужно)
- pathlib, shutil, argparse

## Запуск

```bash
python sorter.py                     # проверка папки «Загрузки», ничего не перемещается
python sorter.py --run               # сортировка «Загрузок»
python sorter.py "D:\Папка" --run    # сортировка любой папки
```

## Попробовать безопасно

```bash
python make_test_folder.py           # создаст на рабочем столе папку с файлами-примерами
python sorter.py "путь к папке" --run
```
